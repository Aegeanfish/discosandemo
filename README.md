# Discos and Demo Static Site

This repository contains a static website with multiple landing page variants (`index.html`, `index-slides.html`, `index-particles.html`, and `index-old.html`). Assets live in the `css`, `js`, `images`, and root icon files.

## Run locally
Use Python's built-in HTTP server to preview the site:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/ in your browser. Stop the server with `Ctrl+C` when you're done.
